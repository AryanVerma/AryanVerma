### Featured project

**[QueryMind](https://github.com/AryanVerma/querymind)** - Text-to-SQL analytics engine.
Ask an analytics question in plain English and get back safe SQL, a result table, and a
one-line summary. No SQL knowledge required.

- **Defense-in-depth safety:** three independent layers block destructive intent - a
  constrained prompt, an AST validator that rejects anything but a single read-only
  SELECT (and blocks read-side exfiltration functions), and a read-only Postgres
  sandbox where a write dies at the database.
- **RAG:** 30 curated few-shot examples in Qdrant with local ONNX embeddings.
- **Stack:** ASP.NET Core (.NET 10) · Vue 3 · Llama 3.3 70B via Groq · PostgreSQL · Qdrant
- 5-panel admin UI to manage schema, examples, query logs, guardrails, and model config.
